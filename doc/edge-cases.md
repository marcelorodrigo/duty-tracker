# Edge Cases

## Days off

A day off on a normally-working day is still treated as a **regular working day**:
- Standby is capped at 15 hours
- Overtime does **not** apply — time-for-time with manager approval instead
- You should not be on-call on days off; arrange for a colleague to cover if possible

## Part-time schedules

If you work part-time and a given weekday is not a normal working day for you:
- Standby follows the non-working-day rules (up to 24h at Mon–Sat rate)
- However, overtime does **not** apply — time-for-time arrangement instead

## Public holidays

- Any day that is a public holiday uses the **Sunday/Holiday** rate for standby
- Overtime on a holiday uses the holiday allowance percentage
- There is no 15-hour cap on holidays

## Working on incidents when not on-call

If you work on an incident outside normal hours but are **not on-call** (either not on a support team or not your on-call week):
- You are **not** entitled to overtime pay
- Time-for-time applies instead (1 hour worked = 1 hour off)
- Always obtain prior manager approval before applying time-for-time

## Incidents during normal working hours

Work performed during your normal working hours is **not claimable** as overtime, even if you are on-call. Only work outside normal hours qualifies.
